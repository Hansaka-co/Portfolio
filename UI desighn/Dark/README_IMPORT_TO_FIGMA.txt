THE ISLAND — DARK / THE STORM
Figma Import Pack

WHAT THIS IS
This pack contains editable SVG screens for the portfolio concept.
It is not a native .fig binary file. Figma's .fig format is proprietary and cannot be created reliably offline.

HOW TO USE IN FIGMA
1. Create a blank Figma Design file.
2. Drag all SVG files from this folder onto the canvas.
3. Figma imports SVG text, shapes, lines, gradients and vectors as editable layers.
4. Keep each imported SVG as its own screen group, or use Frame Selection to convert it into a frame.
5. Install/use Cormorant Garamond and Manrope in Figma if prompted.
6. Replace placeholder email/social links and refine real project content before coding.
